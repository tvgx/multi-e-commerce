# Quy tắc vận hành — multi-ecommerce

Phạm vi: `apps/`, `packages/`, `k8s/`, `docker/`, CI/CD, backup/restore, bảo mật.

**Bắt buộc (người & agent):**
- Đọc [AGENTS.md](../../AGENTS.md) trước thao tác môi trường/quyền.
- KHÔNG push thẳng `main`/production — mọi thay đổi qua PR.
- Thao tác rủi ro (delete, restore, sync→prod): `--dry-run` → backup → PR/issue nhãn `risk/high` → đủ approval → thực hiện → ghi audit.
- KHÔNG ghi/hiện secret trong log/output. Prod: Azure Key Vault; staging: K8s Secrets; local: `.env` (không commit).

**Code & CI:** lint `npm run lint`; test `npm run test`; PR phải CI xanh; coverage vùng quan trọng ≥70–80%; commit `type(scope): mô tả`.

**Nhánh & PR:** `feature/<x>`, `fix/<x>`, `chore/<x>`; checklist: test pass · lint pass · changelog nếu cần · ≥1 reviewer (2 cho thay đổi prod) · đổi infra thì kèm diff + dry-run.

**Hạ tầng:** manifest ở `k8s/` hoặc `apps/*/docker/`; không apply thẳng prod (PR→staging→smoke→prod); cửa sổ deploy theo AGENTS.md; khẩn cấp theo Emergency Override + audit.

**Riêng cho AI agent:** load AGENTS.md + file này trước; yêu cầu mơ hồ → hỏi rõ (env, branch, acceptance); không commit thẳng `main`; code sinh ra phải kèm test; thao tác infra/risk phải kèm dry-run, diff, backup, các bước rollback; đổi cấu trúc dữ liệu → mô tả migration + impact.
