# PR Template

```markdown
## Mô tả
<Thay đổi gì & vì sao>

## Loại
- [ ] feat  - [ ] fix  - [ ] refactor  - [ ] docs  - [ ] chore  - [ ] infra

## Liên quan
Fixes #<issue>

## Kiểm thử
- [ ] Unit/integration test (mô tả ngắn)
- [ ] Đã chạy thủ công (bước)

## Ảnh hưởng & Rollback
- Impact: <breaking? migration? downtime?>
- Rollback: <cách hoàn tác>

## Checklist
- [ ] lint + test xanh  - [ ] docs cập nhật (api-doc nếu đổi API)
- [ ] reviewer được tag  - [ ] infra: kèm diff + dry-run
```
